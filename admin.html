      Participants

      Un nouveau participant n'a personne à offrir tant que tu ne relances pas le tirage (ou que tu ne l'assignes pas à la main).

      NomRôleIdentifiantMot de passe

      Publier les changements

      Le site est statique : tes modifications ne sont visibles par les participants qu'une fois le fichier data/data.json mis à jour sur GitHub.

      Option 1 — Publier directement sur GitHub

      Nécessite un fine-grained token GitHub avec la permission « Contents: Read and write » sur ce dépôt. Il n'est jamais enregistré ailleurs que dans cet onglet.

      Option 2 — Télécharger le fichier

      Télécharge data.json puis remplace data/data.json dans le dépôt (via « Add file → Upload files » sur GitHub).

      Identifiants

      Récupère à tout moment la liste à jour des identifiants et mots de passe.
