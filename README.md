# 🎅 Secret Santa — Section 422

Site du Secret Santa de la section : https://hugoduhen.github.io/Secret-Santa-422/

Choisis ton nom, entre le mot de passe qu'on t'a donné et découvre à qui tu offres un cadeau.

Chaque résultat est chiffré (AES-256-GCM, clé dérivée du mot de passe par PBKDF2) : personne ne peut lire le tirage d'un autre, même en fouillant le code.
